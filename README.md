# LSCI 220 assignment 1, 2025
The task is to do something interesting with NLTK.

I've downloaded some raw text from the archives of Rip It Up magazine, held on the [Papers Past website](https://paperspast.natlib.govt.nz/periodicals/rip-it-up).

Those archives come with this copyright statement:
The masthead, text, artworks, layout and typographical arrangements of Rip It Up are licenced for non-commercial use under a Creative Commons Attribution Non-Commercial Share Alike 3.0 (CC BY-NC-SA 3.0) licence. Rip it Up is not available for commercial use without the consent of Propeller Lamont Ltd.

I believe that this use is consistent with that licence. If I'm wrong, please let me know.

The goal here is to load a number of album reviews from 1977 and more from 1997 and use features of NLTK to find interesting linguistic differences in reviews from these respective eras. These might be vocabulary, writing style, level of formality, complexity of language etc.
